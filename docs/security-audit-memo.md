# 依存関係の脆弱性メモ

最終確認日: 2026-09-17

`npm install` 実行時のnpm監査で、依存関係に既知の脆弱性が **27件** 報告された。

| 重要度 | 件数 |
| --- | ---: |
| 高 | 17 |
| 中 | 7 |
| 低 | 3 |

## 現在の扱い

- 今回はTypeScriptの型エラー解消を目的としたため、`npm audit fix` は実行していない。
- 自動修正にはメジャーバージョン更新やアプリの挙動変更が含まれる場合があるため、検証なしに適用しない。

## 対応時の手順

1. `npm audit` で対象パッケージと依存経路を確認する。
2. 直接依存しているパッケージから、互換性を確認して更新する。
3. `npm audit fix` を使う場合も、変更内容を確認してから実施する。
4. 型チェック・Lint・本番ビルドに加え、記事生成・レビュー・WordPress投稿の主要操作を確認する。

## 補足

このメモの件数は確認時点の値であり、依存関係の更新やnpm監査データの更新により変動する。
